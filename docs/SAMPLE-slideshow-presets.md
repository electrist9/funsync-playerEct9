# 公式サンプル: スライドショー切り替えプリセット（slideshowPresets）

- 日付: 2026-11-25
- 対象: `config.json` の `settings.player.slideshowPresets` / `settings.player.slideshowPreset`
- 実装: `renderer/js/slideshow-timing.js`（rhythmslide `funscript.py` の移植）
- 通常の編集は設定パネルの「再生 → フォトスライドショー → プリセット」から行えます。本書は **プリセットを一括で導入したい方向けの公式サンプル集** です。

## 1. プリセットとは

プリセットは「写真の切り替えタイミングと順序」のまとまりです。1 つのプリセットは次の 5 フィールドで構成されます。

| フィールド | 意味 |
|-----------|------|
| `name` | プリセット名（必須・重複時は先頭のみ有効） |
| `mode` | 切り出し方式: `up` / `peak` / `cumulative` |
| `threshold` | 振幅しきい値（ファンスクリプトの位置 0–100 基準） |
| `step` | 累積移動量のステップ（`cumulative` のみ使用） |
| `order` | 写真の順序: `forward`（順送り）/ `pingpong`（往復） |

プリセットはスライドショー有効化時に適用され、再生中のポップオーバーでの選択はそのセッションのみです。トランジション・背景・写真フォルダはプリセットではなく別設定です。

## 2. 公式サンプル（8 種）

| プリセット名 | mode | threshold | step | order | 特徴・向いている使い方 |
|-------------|------|-----------|------|-------|----------------------|
| 王道（従来動作） | up | 0 | 100 | forward | 上昇ストロークごとに切り替え。rhythmslide の既定動作そのもの |
| 高頻度・切り返し | peak | 0 | 100 | forward | 上昇・下降どちらの方向転換点でも切り替え。最も高頻度で賑やか |
| 揺れノイズ無視 | up | 25 | 100 | forward |振幅 25 以下の小さな上昇を無視。ファンスクリプトの揺れによる誤発火を防ぐ |
| 規則的な一定間隔 | cumulative | 10 | 100 | forward | 累積移動量が 100 ごとの切り替え。揺れ（振幅 10 以下）を数えないので均等な間隔になる |
| ゆっくり安定 | cumulative | 10 | 200 | forward | 前項のステップを 2 倍にしたもの。切り替え頻度はおおむね半分 |
| 往復で単調さ回避 | up | 0 | 100 | pingpong | 従来動作のまま写真の順序を往復に。順送りのループ継ぎ目の「戻り」が消える |
| 映える高頻度＋往復 | peak | 15 | 100 | pingpong | ピーク検出（振幅 15 以上）＋往復。高頻度でも揺れに左右されず単調にならない |
| 大きな山だけ | peak | 45 | 100 | forward | 大きな振幅の方向転換点のみで切り替え。落ち着いて見せたいとき向け |

## 3. 導入方法

1. **FunSync を完全に終了します。** 設定は実行中に `config.json` へ書き込まれるため、起動中に編集すると上書きされて消えます。
2. `config.json` を開きます。
   - ポータブル版（既定）: exe と同じフォルダの `data\config.json`
   - ポータブルでない場合: `%APPDATA%\funsync-player\config.json`
3. `"settings"` → `"player"` の中にある `"slideshowPresets": []` を、下記の配列に置き換えます（他の項目は変更しないでください）。
4. 有効化時に既定で使うプリセット名を `"slideshowPreset"` に指定します（`""` の場合は配列の **先頭** が使われます）。
5. FunSync を起動します。設定パネルのプリセット一覧に表示され、以降は GUI でも編集・削除できます。

## 4. 各 mode の動作

切り替え点は動画のファンスクリプト（アクション配列）から導出されます。最初のアクションは常に切り替え点になりません（1 枚目が t=0 から表示されるため）。

### `up` — 上昇ストロークごと
前のアクション位置より **threshold より大きく上昇した** アクションの時刻で切り替えます。下降では切り替わりません。`threshold: 0` は「すべての上昇」で、rhythmslide の既定です。

### `peak` — 方向転換点（ピーク）
位置の局所最大・局所の最小の両方を検出し、**高さと深さの小さい側が threshold を超える** 転換点で切り替えます。上昇ピークと下降バレーの両方で発火するため、`up` より高頻度になります（1 ストロークで最大 2 回）。

### `cumulative` — 累積移動量
**threshold を超える移動だけの |Δ位置| を累積**し、step に到達するたびに切り替えます。揺れノイズ（振幅の小さい往復）を数えないため、切り替え間隔が規則的になります。`step` がこの方式専用パラメータです。

## 5. `order` の動作

- `forward`: 写真番号 0 → 1 → … → N-1 → 0（ループ）と順送りのまま周回します。
- `pingpong`: 0 → 1 → … → N-1 → N-2 → … → 1 → 0 の三角波で往復します。順送りの周回時に起こる「最後 → 最初」の急な戻りがなくなり、単調さが減ります。

これは設定パネルの「写真リストの並び順（名前順 / ランダム）」とは別の設定で、独立に組み合わせられます。

## 6. 検証とフォールバック

設定の読み込み時に自動的に補正されるため、JSON を直接編集してもアプリが壊れることはありません。

- 名前が空・重複（先頭のみ採用）、配列でない項目は破棄
- 未知の `mode` → `up`、未知の `order` → `forward`
- `threshold` が 0 未満・非数値 → 0
- `step` が 0 以下・非数値 → 100
- 既定プリセットの解決（`slideshowPreset`）: 名前の完全一致 → 見つからなければ配列の先頭 → プリセットがなければ組み込み既定（`up` / 0 / 100 / `forward`）
