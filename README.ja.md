# FunSync Player

> このファイルは [README.md](README.md) の日本語版です。記述に差異がある場合は英語版が優先されます。

funscript 再生向けのデバイス同期機能を備えた、ローカルデスクトップ動画プレイヤー。Electron で構築。Windows と Linux に対応。

**[最新リリースをダウンロード](https://github.com/DaveMakesWaves/funsync-player/releases/latest)**

---

## 機能

### 動画プレイヤー
- カスタムコントロール、キーボードショートカット、ドラッグ＆ドロップを備えた多機能プレイヤー
- シークバーのサムネイルプレビュー（ホバー時のリアルタイムフレームキャプチャ）
- サブタイトル対応（.srt、.vtt）。SRT → WebVTT の自動変換
- スクリーンショット撮影、ピクチャーインピクチャー、アスペクト比の切り替え
- A-B ループポイントで区間リピート
- 動画終了時のリプレイボタン
- スクリプトのギャップ自動スキップ（カウントダウンまたはスキップボタンを設定可能）

### ライブラリ
- 1つ以上のソースフォルダから動画コレクションを閲覧・整理
- **グリッド / リスト / フォルダツリー**表示の切り替え。サムネイルカードとホバープレビュー
- ソースのドラッグ並び替え、ソース別の有効/無効、重複検出、ドライブのホットプラグ検出
- ファイル名による funscript の自動ペアリング（自動/手動バッジ付き）。サブタイトル自動検出
- ファジー検索（完全一致タイトルを優先）。パス + コレクション + カテゴリ一致、アクセント記号の正規化
- 名前、再生時間、平均速度、最大速度での並び替え（一致タブのみ）
- プレイリスト、カテゴリ、コレクション。フォルダをコレクションとしてピン留め
- 複数選択によるプレイリスト/カテゴリの一括割り当て
- スクリプトバリアント検出 — 1本の動画に対する複数の funscript バージョンを自動検出

### リモートアクセス
- **Web リモート** — 同じ Wi-Fi 上のスマートフォンから FunSync を操作。ライブラリ、再生、デバイス同期。スマートフォンのホーム画面に PWA としてインストール可能
- **VR コンテンツサーバー** — HereSphere 経由で Quest スタンドアロンに対応。ライブラリがヘッドセットに表示され、PC に接続されたデバイスは自動同期
- **PCVR コンパニオンブリッジ** — PC 版 HereSphere（SteamVR、Virtual Desktop）をタイムスタンプ API 経由で駆動。すべてのデバイスが付随
- **セッションステータスカード** — 外部ソースが再生を駆動しているときに右下へドック。50件の履歴ビューアと、VR ↔ Web リモートの後勝ちミューテックスを備える

### EroScripts 連携
- アプリ内からコミュニティの funscript を検索・ダウンロード
- 2FA 対応ログイン（認証アプリ）、セッション永続化
- 検索結果にサムネイルとメタデータを表示
- ワンクリックダウンロード — スクリプトは自動でリネーム・関連付けされ、現在の動画とペアリング
- 動画読み込み時の自動マッチング — ローカルにスクリプトがない場合、EroScripts をサイレントに検索して通知

### funscript 対応
- シークバー上のヒートマップオーバーレイ（速度別カラー）
- アイドル区間を示すギャップインジケーター
- ファジー順位付け付きの手動 funscript 関連付け
- スクリプトバリエーション — 再生中に複数のスクリプトバージョンを切り替え（V キー）
- マルチアクスル funscript 対応（TCode 規約、10アクスル）
- **カスタムルーティング** — 動画ごとに異なるスクリプトを異なるデバイスへ割り当て。Intiface 再起動でも安定（インデックス優先マッチング + 名前自動修復）
- 速度統計（平均/最大）をライブラリカードに表示

### スクリプトスムージング
- PCHIP 補間（形状保持、オーバーショットなし）でより滑らかなデバイス動作
- Makima 補間（より緩やかで、振動的パターンに適する）
- 設定可能な速度制限で、物理的に不可能な動きを防止
- 設定の永続化 — 一度設定すればすべての再生に適用

### デバイス連携
- **The Handy** — HSSP クラウド同期、スクリプト自動アップロード、ドリフト検出、10秒ごとのクラウドヘルスチェック（BT モード切り替えを検知）
- **Buttplug.io** — Intiface Central 経由で 700 以上のデバイスに接続（ストローカー、バイブ、ロテーター、e-stim）
  - **機能別の ON/OFF** — 複数の機能（例：回転 + 振動）を持つデバイスで、funscript が実際に駆動する出力を選択できます。無効にした機能はアイドルのまま、他の機能は同期を継続します。
  - **機能別の範囲（range）と出力制限（cutoff）** — 機能ごとに **range**（再スケール：その機能の 0〜100 が最小〜最大の窓に割り当てられます。単なるクランプではなく変換されます）と **cutoff**（ハードクリップ：下限未満は下限に固定、上限超過は上限に固定され、その間の値はそのまま再生されます）を設定できます。どちらも既定値 0/100 は無効を意味し、設定はデバイスごとに保存されて再接続後も復元されます。編集は機能別チェックボックス横のコンパクトな**チップ**から行います。チップには要約（例：`範囲 20–80 制限 0–60`）が表示され、クリックすると Range と Limits のフィールドとリセットボタンを備えた小さなポップオーバーエディタが開くため、デバイスカードはすっきりしたままです。
  - **適用順（パイプライン）** — funscript 位置 → スムージング / 速度制限 / extender → 反転 → デバイス range（再スケール） → デバイス cutoff（クリップ） → **機能別 range（再スケール） → 機能別 cutoff（クリップ）** → 安全キャップ（Max 強度 + ramp-up、scalar/oscillate デバイスのみ） → デバイス。安全キャップは常に最後に適用されるため、機能の下限で Max 強度制限を迂回することはできず、上限がそれを上回る場合もキャップされます。
- **TCode シリアル（OSR2 / SR6）** — USB シリアル。全10アクスルのアクスル別有効化 + min/max 制御（実験的）
- **Autoblow Ultra / VacuGlide 2** — クラウド API（実験的）
- **起動時の自動接続** — 事前に設定済みであれば Handy と Buttplug.io が自動接続
- デバイス別のオフセット制御 + 合計実効オフセット（VR + デバイスの合成）を表示する統合 Sync タブ
- ストローク位置をリアルタイム表示するデバイスシミュレーターオーバーレイ
- デバイス未接続でも完全に動作 — 純粋な動画再生はそのまま利用可能

### スクリプトエディター（実験的）
- 中央プレイヘッドと速度別カラーラインを備えた OFS スタイルのアクショングラフ
- テンキー配置（0-9 が位置 0-100 に対応）、フレーム単位の送り、スナップ切り替え
- 選択、コピー/ペースト、undo/redo（スクリプト別の履歴永続化）
- マルチアクスル / カスタムルーティング編集用のマルチスクリプトセレクター
- 修正ツール：半減/倍速、範囲のリマップ、時間オフセット、ポーズ除去、反転
- パターン生成：サイン、ノコギリ、スクエア、トライアングル、エスカレーティング、ランダム
- ギャップ検出と、パターン設定可能な埋め戻し
- 音声波形表示とビート検出（音楽同期スクリプティング用）
- メタデータエディター（タイトル、作成者、タグ、パフォーマー）
- グラフ上の名前付きマーカーとしてのブックマーク
- テンキー配置時のライブデバイスプレビュー（同期エンジンがアイドルの場合）
- 自動保存トグル（既定オフ、有効時は保存タイムスタンプを表示）

### マルチアクスル対応（実験的）
- TCode 規約の検出（10標準アクスル）
- ファイル名サフィックスによるコンパニオンファイル検出
- アクスルからデバイス機能へのマッピング
- ファジーマッチ付きの検索可能ドロップダウンによるアクスル割り当て

### データ
- 設定、プレイリスト、カテゴリはローカル保存（クラウドなし、アカウント不要）
- .funsync-backup zip ファイルによるバックアップのエクスポート/インポート
- 自動アップデート — 新バージョンの通知は行いますが、**ダウンロードもインストールもあなたの判断**（終了時のサイレントインストールなし）
- すべてのユーザーデータはアップデートをまたいで保持

## インストール

1. [Releases ページ](https://github.com/DaveMakesWaves/funsync-player/releases/latest)から最新インストーラーをダウンロード
   - **Windows**: `FunSync Player Setup X.Y.Z.exe`
   - **Linux**: `FunSync-Player-X.Y.Z.AppImage`
2. インストーラー / AppImage を実行
   - Windows: 管理者権限不要、ユーザー単位でインストール
   - Linux: AppImage に `chmod +x` して実行
3. アプリが自動で起動

アップデートは起動時にチェックされます。新バージョンがある場合はトーストが表示されます — Download をクリックし、準備ができたら Restart Now を押してください。

## キーボードショートカット

| キー | 動作 |
|-----|--------|
| Space / K | 再生 / 一時停止 / リプレイ |
| 左 / 右 | 5秒シーク |
| J / L | 10秒シーク |
| 上 / 下 | 音量 |
| M | ミュート |
| F / F11 | フルスクリーン |
| O | ファイルを開く |
| H | デバイスパネル |
| S | スクリーンショット |
| I | 情報オーバーレイ |
| A / B | ループポイント |
| Escape | ループ解除 / パネル閉じ |
| R | アスペクト比切り替え |
| E | スクリプトエディター切り替え |
| D | デバイスシミュレーター切り替え |
| V / Shift+V | スクリプトバリアント切り替え |
| G / Shift+G | 次の/前のアクションへジャンプ |

### スクリプトエディター（キャンバスがフォーカスされているとき）

| キー / マウス | 動作 |
|-------------|--------|
| 0-9 / テンキー 0-9 | 現在のプレイヘッド位置にアクション配置（位置 0, 11, 22, ..., 100） |
| 空のキャンバスを Alt+クリック | クリック位置にアクション挿入 |
| 左 / 右 | 動画1フレーム送り |
| Ctrl+左 / 右 | 高速フレーム送り（既定 6 — `editor.fastStepFrames`） |
| Shift+左 / 右 | 選択アクションを時間上で ±1 フレーム移動 |
| Ctrl+Shift+左 / 右 | 選択アクションを時間上で ±N フレーム移動 |
| 上 / 下 | 前 / 次のアクションを選択（シーク付き） |
| Ctrl+上 / 下 | 読み込み済み全スクリプト横断で前 / 次のアクションを選択 |
| Shift+上 / 下 | 選択アクションの位置を ±5 調整（粗く） |
| Ctrl+Shift+上 / 下 | 選択アクションの位置を ±1 調整（細かく） |
| Delete / Backspace | 選択アクションを削除 |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+C / V / X | コピー / ペースト / 切り取り |
| Ctrl+A | すべて選択 |
| Ctrl+I | 位置を反転 |
| Ctrl+S | 保存 |
| W | 音声波形オーバーレイ切り替え |
| B | 現在位置にブックマーク追加 |
| +/- | ズームイン / アウト |
| Escape | 選択解除 / エディター閉じ |

アクション配置時：プレイヘッドを動かさずにテンキーを押すと、直前に配置したアクションの高さを調整できます。プレイヘッドをシークしてからテンキーを押すと、新しい時刻に新しいアクションを配置できます。

## 動作要件

- Windows 10/11 (x64) または Linux（AppImage — Ubuntu 22+、Fedora 38+、SteamOS）
- Buttplug.io デバイス対応には [Intiface Central](https://intiface.com/central/) が必要（任意）

---

## ソースからのビルド

```bash
npm install
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements.txt && cd ..
npm run build
```

Node.js 18+、Python 3.11+、および `ffmpeg/` ディレクトリ（Linux は `ffmpeg-linux/`）内の ffmpeg/ffprobe バイナリが必要です。
